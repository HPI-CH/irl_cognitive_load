# Analyzing Cognitive Load of Software Developers Using Wearables During Their Everyday Work

This repository contains the Python code used for the paper draft:

> **Analyzing Cognitive Load of Software Developers Using Wearables During Their Everyday Work**

The repository provides scripts and workflows for data preprocessing, feature engineering, and machine learning analyses used throughout the study.

## Repository Structure

```text
.
├── PREP/
│   ├── README.md
│   └── ...
├── Modeling/
│   ├── README.md
│   └── ...
└── README.md
```

### PREP

The `PREP` directory contains the code for data preparation and preprocessing. This includes processing raw wearable sensor data, cleaning datasets, feature extraction, and preparing data for downstream analyses.

Further instructions can be found in:

```text
PREP/README.md
```

### Modeling

The `Modeling` directory contains the code for statistical analyses and machine learning models used in the study.

Further instructions can be found in:

```text
Modeling/README.md
```

## Environment Setup

Detailed instructions for creating and configuring the required Python environments are provided in the README files of the respective subdirectories:

- `PREP/README.md`
- `Modeling/README.md`

## Reproducibility

The repository is organized to facilitate reproducibility of the analyses presented in the paper. Each module contains its own documentation, dependencies, and execution instructions.
